# Stream Hub v0.1.7

Release status: **field accepted on Odroid C4 and TrueNAS SCALE**

## Hub

- Added a persistent stream library independent from device playlists.
- Added TXT and JSON bulk import with per-row validation results.
- Added ID/URL search, visible-item selection and bulk deletion.
- Added a device playlist picker that inserts library streams disabled by
  default; no device configuration changes until the operator explicitly
  saves and sends it.
- Removed the browser Basic Auth challenge header so the normal cookie-based
  login page is always shown.
- Added a fleet-wide stream library containing verified HLS, RTMP, RTSP and
  UDP multicast sources without changing device playlists.

## Odroid player

- Added bounded FFprobe validation and playback for IPv4 UDP/RTP multicast.
- Added a protocol-specific low-latency MPV profile for multicast while
  retaining the existing HLS/RTMP/RTSP buffering profile.
- Preserved the persistent-MPV `loadfile replace` transition, playback
  watchdog and reconnect behavior.

## Safety

- The library starts empty and does not seed or modify any device playlist.
- Library deletion never removes entries already present in device playlists.

## Validation

- Full automated suite: `91 passed`.
- Multicast playback was accepted on physical Odroid C4 hardware.
- The player update was deployed to 13 devices while preserving every
  existing playlist; the final fleet check reported `13/13` online and
  `13/13` playing.
- The live Hub library contains 42 sources: 35 UDP multicast, 3 RTMP, 1 RTSP
  and 3 HLS. Mist multicast addresses use the final mapping from
  `239.10.10.1:6000` through `239.10.10.7:6006`.
