# Stream Hub v0.1.8 — sound

- Per-device persistent audio enable/mute, volume 0–100 and auto/HDMI/USB output.
- Hub controls saved using the existing configuration revision/heartbeat flow.
- Audio disabled by default for legacy and new configurations.
- Explicit USB/HDMI selection resolves ALSA card names, not volatile card numbers.
- Missing explicitly selected output fails closed instead of leaking audio to another output.
- Existing playlists are preserved during software deployment.
- Public images contain an empty playlist and disabled audio; no operational credentials.
- Physical amplifier output still requires operator acceptance at a safe level.

## Validation

- 97 automated tests passed, including legacy defaults, bounds, USB routing,
  missing-device fail-closed behavior and Hub-to-device config round trips.
- Hub image smoke test confirmed OpenAPI 0.1.8 and the audio schema.
- 14 devices received the software update; every existing playlist file hash
  was preserved. Audio was enabled only on the dedicated USB sound device.
- Hardware amplifier listening and newly flashed eMMC boot acceptance remain
  separate operator checks; automated image validation does not replace them.
