# Stream Hub v0.1.1

Release status: **field validated**

## Playback change

- The player now uses one persistent GStreamer compositor with A/B HLS
  branches.
- A new stream is decoded in the background and is not shown until its first
  real video buffer arrives.
- The old stream remains fully visible during preroll. A successful switch uses
  an approximately 400 ms alpha crossfade.
- A failed or timed-out preroll is discarded without hiding the current stream.
- Old branch teardown happens after the visual transition and does not block
  the next playlist operation.

## Field acceptance

- The offline Ubuntu 22.04 ARM64 GStreamer runtime was deployed to eight
  physical Odroid C4 devices.
- All eight devices reported `stream-player.service` and
  `stream-agent.service` active, player state `playing`, package audit clean,
  and zero player service restarts.
- Multi-stream devices measured successful fades between 403 and 411 ms.
- The Hub reported all eight devices online with player `active/playing` and
  configuration status `applied`.
- 54 automated tests pass.

## Offline clone support

The v0.1.1 image embeds 66 Ubuntu 22.04 ARM64 packages. On the first boot, before
the agent or player starts, the clone:

1. installs the embedded runtime without internet access;
2. verifies `compositor`, `input-selector`, `fbdevsink`, `avdec_h264`, and
   `hlsdemux`;
3. removes the package bundle;
4. generates its unique identity, expands the filesystem, and reboots.

If runtime installation fails, the golden-image marker remains in place and the
agent/player stay blocked instead of starting with a partial installation.

## Public image

The public image is derived from the separately sanitized v0.1.0 public image,
not from the private operational image. The following were re-audited:

- default Linux passwords: `root` / `odroid` and `odroid` / `odroid`;
- no device registration or command-result files;
- no authorized keys or SSH host keys;
- empty machine ID, random seed, logs, and shell histories;
- empty revision `0` playlist;
- first-boot marker and service enabled;
- default Hub URL: `http://192.168.100.142:8788`.

Change both Linux passwords immediately after first boot.
