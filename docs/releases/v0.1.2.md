# Stream Hub v0.1.2

Release status: **field validated**

## RTMP support

- Hub and Odroid playlist models accept `http://`, `https://`, `rtmp://`, and
  `rtmps://` stream addresses.
- RTMP source health is measured with the bundled `ffprobe` runtime.
- The player probes an RTMP source before issuing MPV IPC
  `loadfile <url> replace`, so an unreachable source does not replace the
  currently visible stream.
- RTMP preflight has a dedicated eight-second handshake allowance while HLS
  retains the existing short HTTP precheck.
- Structured FastAPI validation errors are rendered as readable UI messages
  instead of `[object Object]`.

## Field acceptance

- A real RTMP source was probed from the physical acceptance Odroid and
  reported both video and audio streams.
- The complete Hub-to-device flow was verified on `192.168.102.228`: config
  applied, player state `playing`, active stream `salon1`, RTMP health
  `ok=true`, and both services active with zero automatic restarts.
- The acceptance device's original 27-stream HLS playlist was restored after
  the test.
- The final player, model, and health files were deployed to 13 physical
  Odroid C4 devices.
- Final fleet validation reported 13/13 devices online, 13/13 players active,
  and 13/13 configurations applied.
- 59 automated tests pass.

## Clone behavior

On first boot, the clone generates unique machine and SSH identities, expands
the root filesystem, removes the image marker, and reboots before the agent or
player starts. The image contains the field-tested persistent-MPV player and
the RTMP-capable agent runtime.

## Public image security

The public image is derived from the separately sanitized v0.1.1 public image,
not from the private operational image. The v0.1.2 audit verified:

- default Linux passwords: `root` / `odroid` and `odroid` / `odroid`;
- no device registration, token, or command-result files;
- no authorized keys or SSH host keys;
- empty machine ID, random seed, leases, journal, and shell histories;
- empty revision `0` playlist;
- first-boot marker and agent/player/firstboot services enabled;
- default Hub URL: `http://192.168.100.142:8788`.

Change both Linux passwords immediately after first boot.
