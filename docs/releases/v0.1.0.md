# Stream Hub v0.1.0

Release status: **field validated**

## Validated environment

- Odroid C4
- Ubuntu 22.04 LTS, aarch64
- TrueNAS SCALE Hub host
- Routed deployment with Hub and players on different IPv4 subnets
- HLS playback through MPV SDL framebuffer output

## Validated capabilities

- one-command Odroid and Hub installation with runtime dependencies;
- automatic device registration, approval, naming, and 10-second heartbeat;
- playlists with up to 50 stream links;
- per-stream health checks from the actual Odroid network path;
- central playlist delivery with revision/result tracking;
- player restart and Odroid reboot commands;
- CPU, memory, disk, log usage, uptime, temperature, and player telemetry;
- seven-day, maximum 1 GB device journal policy;
- clone-safe golden-image first boot with unique hostname, machine ID, SSH
  host keys, Hub identity, filesystem expansion, and one automatic reboot;
- TrueNAS persistence, bounded container logs, and SQLite backups.

## Acceptance evidence

- 46 automated tests pass.
- Ubuntu 22.04/aarch64 installation was completed on physical Odroid C4
  hardware.
- Multiple devices registered from routed subnets and remained online.
- Playlist config reached matching desired/reported revisions with `applied`
  status.
- Player restart, reboot delivery, playback progression, and framebuffer
  updates were verified on hardware.
- The corrected golden image was written to a separate eMMC and the complete
  first-boot, registration, config, and playback flow was confirmed.

## Distribution

This GitHub release contains:

- source archives generated by GitHub;
- independent one-command Odroid and Hub installation archives;
- SHA-256 checksums;
- a separately sanitized Odroid C4 public image compressed with Zstandard.

The operational field image remains private. The public image was derived into
a separate file and audited offline. Device registration/token files,
authorized keys, SSH host keys, machine ID, random seed, logs, histories,
leases, and deleted free-space data were removed.

Public-image defaults:

- Linux accounts: `root` / `odroid` and `odroid` / `odroid`;
- Hub URL: `http://192.168.100.142:8788`;
- playlist: empty revision `0` template.

Change the Linux passwords immediately after the first boot. For a different
Hub address, replace
`/etc/systemd/system/stream-agent.service.d/hub.conf`.
